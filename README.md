# mcp-client-metadata

Public OAuth client metadata documents (CIMD, draft-ietf-oauth-client-id-metadata-document)
for self-hosted MCP clients on Rico's machines. Contains no secrets.

- `bubble-client.json` — client for Bubble's MCP server (https://mcp.bubble.io/mcp),
  used by prime-agent on lab. Redirect URIs point at lab's tailnet HTTPS and loopback.
